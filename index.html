🤖 Крок 2. Отримання та збереження HTML-коду
💡 Вам НЕ потрібно писати код самостійно! ШІ згенерує для вас повністю готовий файл. Ваше завдання — скопіювати його без змін.
1
Відкрийте ChatGPT (або Claude / Gemini).
2
Вставте скопійований з Кроку 1 промпт у поле повідомлення та натисніть Надіслати.
3
ШІ згенерує блок з кодом. У верхньому правому кутку блоку з кодом натисніть кнопку Copy code (Скопіювати код).
🚀 Крок 3. Покрокове створення вебіграшки на GitHub Pages
1
Увійдіть на свій акаунт у GitHub.com.
2
У верхньому правому кутку екрана натисніть значок + ➔ оберіть New repository (Новий репозиторій).
3
У полі Repository name напишіть англійською назву вашої гри (наприклад: my-game або kids-app). Переконайтеся, що обрано Public, і обов'язково поставте галочку Add a README file. Натисніть зелену кнопку Create repository.
4
У створеному репозиторії натисніть кнопку Add file ➔ оберіть Create new file.
5
У верхньому полі назви файлу ОБОВ'ЯЗКОВО НАПИШІТЬ ЧІТКО: index.html (суто малими літерами).
6
У велике текстове поле знизу вставте скопійований з ChatGPT код (Ctrl + V).
7
Натисніть зелену кнопку Commit changes... у правому верхньому кутку та підтвердіть збереження, натиснувши Commit changes.
8
Публікація гри в інтернет: Перейдіть у вкладку Settings (Налаштування) зверху ➔ у лівому меню натисніть Pages ➔ у блоці Branch виберіть main (або master) ➔ натисніть Save.
9
Зачекайте 1–2 хвилини, оновіть сторінку F5. Угорі з'явиться зелене посилання на вашу гру видами: https://username.github.io/my-game/. Скопіюйте його!
🌐 Крок 4. Вбудовування гри у персональний Google Сайт
1
Відкрийте ваш персональний Google Сайт у режимі редагування.
2
На правій панелі інструментів натисніть кнопку Вставити (Embed) ➔ оберіть вкладку З URL-адресою.
3
Вставте скопійоване посилання вашого сайту з GitHub Pages (наприклад: https://...github.io/my-game/) та натисніть Вставити.
4
Розтягніть вікно з грою на потрібну ширину сторінки та натисніть кнопку Опублікувати на Google Сайті.
💡 Зауваження: За бажанням у майбутньому у цю вебіграшку або поруч на сторінці ви зможете додавати додаткові матеріали з Canva, Всеосвіти чи LearningApps, але ваша згенерована вебіграшка вже є повністю автономною та працює самостійно!
